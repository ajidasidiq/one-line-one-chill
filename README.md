## What it does
Writes one original line of horror — a single sentence under 200 characters — to `/output/entry.txt`: the coroner calls to say the narrator's autopsy is finished, and asks why he keeps answering.

> The coroner called to say my autopsy was finished, and asked why I kept answering.

## How to run
```sh
node main.ts
```
Then read `/output/entry.txt`.
